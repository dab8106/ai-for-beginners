## A note on the invoice lab

[Lecture 26: Get Clean JSON From AI in Python (Invoice Example)](https://www.youtube.com/watch?v=a13xeKA5zqc) says the lab reads ten sample invoices. The lab uses three, each with a different layout, and one with a mistake printed on it, which is enough to see every check at work. The notebook reads every image you upload, so you can add your own made-up invoices to try more.
