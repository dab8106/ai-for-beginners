# Your first prompts: starter sheet

Copy each prompt exactly, so your results can be compared with your classmates'.

## Prompt 1: Getting to know the assistant

```
I'm starting a free course on AI for beginners. In five short bullet points,
tell me what an AI assistant like you is good at. Then give me three things
I should not rely on you for. Keep it simple, with no jargon.
```

## Prompt 2: A follow-up in the same chat

```
Explain your first bullet point again, as if I were twelve years old,
in two sentences.
```

## Prompt 3: A small everyday task

```
Write a polite WhatsApp message to the secretary of my housing society,
asking when the water tank will next be cleaned and whether we need to
store water that day. Under 50 words.
```

## One habit, from today

Before you send anything to an AI tool, ask yourself: would I post this in a public group?

If not, don't send it. Never send passwords, bank or card details, ID numbers, or client and company data. Swap real names and numbers for made-up ones, such as "client A" and "amount X".
