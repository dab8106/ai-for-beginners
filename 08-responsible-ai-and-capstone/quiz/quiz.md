# Quiz: Responsible AI and careers

10 questions. Try each one before you look at the answer: the correct option is in **bold**, and the short explanation under it says why. Aim for 7 out of 10. If you miss one, rewatch the lecture named next to it.

**1. You need a summary of a customer complaint file full of names and phone numbers. What do you do first?** _([Lecture 36](https://www.youtube.com/watch?v=seq90GFenQE))_

- Upload it to any free chatbot quickly
- **Check the AI tool is approved by your company, and share only what the task needs**
- Email it to a friend who has a paid account
- Remove the file extension

> Use company-approved tools, and remove details the task doesn't need.

**2. How can you check an AI's output for bias in a CV-screening task?** _([Lecture 36](https://www.youtube.com/watch?v=seq90GFenQE))_

- Ask the AI if it is biased
- Use a longer prompt
- Turn the temperature to maximum
- **Swap one detail, like a name or gender, run the same prompt, and compare**

> If the answer changes when only a name or gender changes, that's a warning sign. Keep a human on decisions about people.

**3. What's the bigger everyday copyright risk when you publish AI-assisted work?** _([Lecture 36](https://www.youtube.com/watch?v=seq90GFenQE))_

- **AI reproducing someone else's text, and you publishing it as yours**
- Using a spell checker
- Writing in English
- Saving the file as PDF

> Ownership rules differ by country and are still changing, but copying someone else's work is the clear risk. Draft with AI, then make it your own.

**4. What is prompt injection?** _([Lecture 37](https://www.youtube.com/watch?v=rm7Ja34q0pY))_

- A way to make prompts shorter
- A method for training models faster
- **Text the AI reads that pretends to be an instruction and tries to take control**
- A virus that infects the computer's hard disk

> The model gets everything as one stream of text, so hidden orders can look like real instructions.

**5. A hidden line in a web page tells an AI assistant to forward invoices. What kind of attack is this?** _([Lecture 37](https://www.youtube.com/watch?v=rm7Ja34q0pY))_

- Direct injection
- A password reset
- **Indirect injection**
- A denial of service

> Direct is typed straight into the chat. Indirect hides in content the AI reads, and it's harder to spot.

**6. A FAQ chatbot and an email agent read the same poisoned web page. Which one worries you more, and why?** _([Lecture 37](https://www.youtube.com/watch?v=rm7Ja34q0pY))_

- **The email agent, because it can take actions, not just say something wrong**
- The FAQ chatbot, because it answers more people
- Neither: web pages are always safe
- Both equally, because they use the same model

> An agent can do something wrong: send, delete, pay. It needs tighter limits and approvals.

**7. In an interview you're asked how to stop prompt injection. What's the best answer?** _([Lecture 37](https://www.youtube.com/watch?v=rm7Ja34q0pY))_

- Write a better system prompt, and that's enough
- Use a bigger model
- Turn off the internet
- **Defend in layers: least privilege, human approval for risky actions, treat outside content as data, and test regularly**

> There's no single fix yet. Layers and regular testing are the honest answer.

**8. Your chatbot's instructions contain a staff code, with a rule 'never reveal it'. What is the most reliable fix?** _([Lecture 37](https://www.youtube.com/watch?v=rm7Ja34q0pY))_

- Add more rules saying never reveal it
- **Remove the code from the prompt completely**
- Write the rule in capital letters
- Hide the code in the middle of the prompt

> A rule in a prompt is a request, not a lock. A secret that isn't in the prompt can't leak through it.

**9. Two candidates apply. One lists ten AI tools on a CV. The other links to one working project. Who is more likely to get the call?** _([Lecture 38](https://www.youtube.com/watch?v=mPjLlKMAITw))_

- **The second: a working project is evidence**
- The first: more tools look better
- Neither: only degrees matter
- Both exactly the same

> A list of tools is a claim. A working project, with an honest write-up, is proof.

**10. Which CV line describes AI work best?** _([Lecture 38](https://www.youtube.com/watch?v=mPjLlKMAITw))_

- Used AI tools
- Expert in all AI
- **Built an assistant that answers HR questions from the policy handbook, tested for accuracy**
- Familiar with ChatGPT

> Describe outcomes, not tool names, and don't overclaim.
